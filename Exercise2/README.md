# Goals

Create a graph where you pass in a single list of integers
along with a name and an operation. If the operation is a
plus, then you add all the elements in the list, and if its a
asterisk, then you multiply all the elements in the list.

Ex:
{"name": "Bob", "values": [1, 2, 3, 4], "operation": "+"}
Output:
"Hi Bob, your answer is: 10"
